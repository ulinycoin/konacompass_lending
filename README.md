# KonaCompass

Рабочая папка проекта по разработке нового лендинга, упаковке бренда и подготовке системы продаж для продукта Kona Compass.

## Структура

- `docs/project/` — цели, scope, spec, acceptance criteria, roadmap
- `docs/brand/` — позиционирование, tone of voice, бренд-платформа
- `docs/product/` — описание продукта, FAQ, discovery по продукту
- `docs/marketing/` — контент, каналы продвижения, GTM
- `docs/seo/` — SEO-аудит, SEO-стратегия, структура страниц
- `docs/sales/` — воронка, лиды, обработка заявок, CTA
- `research/` — OSINT, рынок, конкуренты, пользовательские сегменты
- `assets/` — исходники фото, видео, референсы, логотипы
- `landing/` — будущие файлы сайта / прототипы / реализация

## Ближайшая цель

Собрать полную исходную документацию и зафиксировать основу проекта до начала дизайна и разработки.
