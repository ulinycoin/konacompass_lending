# Kona Compass — Go-To-Market v1

## Каналы старта
1. Сайт / лендинг
2. Instagram
3. YouTube short demos / installation clips
4. Рыболовные сообщества / форумы / Facebook groups
5. Direct outreach to anglers / dealers

## Контент, который нужен в первую очередь
- Hero demo video
- Product in use photos
- Compatibility visuals
- Short explainer: how it works
- Installation content
- FAQ content
- Comparison with alternatives

## First 30 days after launch
- запуск обновлённого сайта,
- публикация 5–10 базовых контент-единиц,
- настройка аналитики,
- сбор первых лидов,
- тест 1–2 каналов привлечения.

## Risks
- мало медиа-материалов,
- мало отзывов,
- сложный технический продукт для холодного трафика,
- слабое текущее доверие к бренду.

## Antidote
Нужна сильная визуальная демонстрация и честное техничное объяснение продукта.
