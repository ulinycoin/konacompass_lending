# Kona Compass — Brand Platform v1

## Рабочая гипотеза бренда
Kona Compass — это технически уверенный бренд для рыболовов, которым нужна точность, контроль и преимущество при работе с live sonar.

## Категория
Smart live sonar transducer rotator.

## Brand Promise
Точное и удобное управление live sonar без лишней суеты и кустарных компромиссов.

## Functional Value
- точное наведение датчика,
- удобное управление,
- стабильная работа,
- совместимость с ключевыми системами,
- повышение эффективности live sonar на воде.

## Emotional Value
- контроль,
- уверенность,
- ощущение технологического преимущества,
- профессиональный подход вместо самодельного решения.

## Positioning Draft
For serious anglers using live sonar, Kona Compass is a precision rotator system that gives clearer control over transducer direction and scanning, helping users work faster, smarter, and with more confidence on the water.

## Attributes
- precise
- rugged
- technical
- reliable
- focused
- purpose-built

## Tone of Voice
- технический, но понятный,
- уверенный,
- без маркетинговой воды,
- без дешёвого “супер-инновационного” пафоса,
- ближе к профессиональному инструменту, чем к игрушке.

## Anti-Brand Traits
- кустарность,
- визуальная дешевизна,
- шумный псевдо-premium,
- generic gadget aesthetic,
- пустые обещания без демонстрации.

## Messaging Pillars
1. Precision / точность.
2. Control / контроль.
3. Compatibility / совместимость.
4. Reliability / надёжность.
5. Real use on the water / реальный сценарий использования.
