## Page Title
User Manual

## Hero Intro
This page gives you a quick and practical guide to the main Kona Compass controls, operating modes, and adjustment logic.

It is designed to help you understand how the system behaves on the water and how to use the core controls with confidence.

---

## 1. Quick Start

When the device powers on, it automatically enters **Manual Mode**.

From there, the main control button is used to switch between key operating modes.
Pedal combinations are used to adjust rotation speed and auto-search sector width.

---

## 2. Operating Modes

### Manual Mode
**Activation:** automatic on power-on

Manual Mode gives you direct control over transducer direction.
Use this mode when you want immediate and simple directional control.

### Direction Hold Mode
**Activation:** short press of the main button

Direction Hold Mode helps keep direction more stable once you have aimed where you want.
Use it when you want more consistent directional control without constant correction.

### Auto Search Mode
**Activation:** press and hold the main button for 2 seconds

Auto Search Mode sweeps the selected sector automatically.
Use it when you want to cover water more efficiently and scan for activity without constant manual repositioning.

### Direction Lock Mode
**Activation:** press and hold the main button for 3 seconds

Direction Lock Mode locks the chosen direction.
Use it when you want fixed directional positioning and repeatable control.

---

## 3. Rotation Speed Adjustment

Rotation speed can be adjusted across all modes.
The system provides **6 speed levels**.

### To decrease rotation speed
Hold the **left pedal** and press the **main button**.

### To increase rotation speed
Hold the **right pedal** and press the **main button**.

Use lower speed when you want finer, more controlled movement.
Use higher speed when you need quicker directional response.

---

## 4. Sector Adjustment in Auto Search Mode

When using Auto Search Mode, the search sector can be adjusted depending on how wide or narrow you want the scan to be.

### To decrease search sector angle
Hold the **main button** and press the **left pedal**.

### To increase search sector angle
Hold the **main button** and press the **right pedal**.

A narrower sector is useful when you want more focused scanning in a specific direction.
A wider sector is useful when you want to cover more water.

---

## 5. Controls Overview

### Main button
Used to switch operating modes and modify settings together with pedal input.

### Left pedal
Used for reducing rotation speed or narrowing the search sector, depending on the active command.

### Right pedal
Used for increasing rotation speed or widening the search sector, depending on the active command.

### Remote control
The product is also presented as supporting remote control for practical operation on the water.

---

## 6. Practical Use Tips

- Start in Manual Mode to get familiar with directional response.
- Use lower speed for fine positioning.
- Use higher speed when reacting to fast movement.
- Use a narrower search sector when you want tighter scanning.
- Use a wider search sector when searching across a broader area.
