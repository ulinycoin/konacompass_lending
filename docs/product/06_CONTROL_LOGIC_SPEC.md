# Технический стандарт: Логика управления ротатором Kona Compass (Rotator V1)

Авторитетный источник истины по логике кнопок, режимов и дисплея.

---

## 1. Визуальная индикация и режимы (Центральная кнопка)

Центральная кнопка — трёхцветная подсветка. Цвет = текущий режим. Дисплей (белые цифры) показывает номер режима у соответствующей иконки.

| Режим | Цвет кнопки | Индикатор | Иконка |
|---|---|---|---|
| №0 «Ожидание» | Выключена | 0 | ∅ |
| №1 «Компас» | Зелёная | 1 | 🧭 |
| №2 «Автопоиск» | Оранжевая | 2 | 🔍 |
| №3 «Фиксация» | Красная | 3 | 🔒 |

### Логика центральной кнопки

| Действие | Результат | Звук |
|---|---|---|
| Короткий клик | Цикл режимов: 1 → 2 → 3 → 1 | N коротких сигналов (N = номер режима) |
| Удержание 0.5 с | Возврат в Режим №0 «Ожидание» | Длинный сигнал |
| Удержание 2.0 с (только Режим №1) | Вход в «Про-Компас», дисплей «≡» | При 0.5 с — длинный; при 2.0 с — двойной длинный |
| Удержание 3.0 с (только Режим №0) | Полное обесточивание системы | Двойной длинный сигнал |

---

## 2. Конфигурация дисплея и настроек

Дисплей показывает только строки, активные в текущем режиме. Все параметры имеют **5 уровней**, переключаемых циклически.

### Иерархия строк (кнопка «Вверх» перемещает курсор снизу вверх)

| Строка | Активна в | Параметр |
|---|---|---|
| Верхняя | Режим «Снайпер» | Угол наклона |
| №3 | Режим №2 «Автопоиск» | Скорость вращения сектора |
| №3 | Режим №0 «Ожидание» | Яркость (L) |
| №2 | Режим №2 «Автопоиск» + Про-Компас | Размер сектора |
| №2 | Режим №0 «Ожидание» | Звук (b) |
| №1 (нижняя) | Всегда | Скорость педали |

---

## 3. Функционал кнопок навигации

### Кнопка «Вверх» (Выбор строки меню)

| Действие | Результат | Звук |
|---|---|---|
| Короткий клик | Циклический переход по активным строкам снизу вверх | N коротких сигналов (N = номер строки) |
| Удержание 0.5 с | Вход в режим «Снайпер» | Длинный сигнал |
| Короткий клик (в «Снайпере») | Выход в основное меню | Короткий сигнал |

### Кнопка «Вправо» (Изменение параметров)

| Действие | Результат | Звук |
|---|---|---|
| Короткий клик | Цикл значения строки: 1→2→3→4→5→1 | Позиции 1–4: короткий; позиция 5: двойной короткий |
| Удержание 0.5 с | Мгновенный сброс параметра на позицию 1 | Длинный сигнал |

---

## 4. Режим «Снайпер» (Управление наклоном датчика)

Активна верхняя строка. Кнопка «Вправо» управляет наклоном: 0° → 15° → 30° → 45° → 60° → 0°.

| Действие | Результат | Звук |
|---|---|---|
| Короткий клик | Шаг вниз на 15° | Короткий (на 60° — двойной короткий) |
| Удержание 0.5 с | Автоподъём в горизонт (0°) | Длинный сигнал |
| Удержание 1.0 с | Автоспуск вниз / Парковка | Двойной длинный сигнал |
| Клик во время движения | «Стоп-кран» — мгновенная остановка | — |

---

## 5. Алгоритм работы педали

| Действие | Результат |
|---|---|
| Длительное нажатие | Вращение штанги |
| Одиночный клик + Удержание | Вращение на Турбо-скорости |
| Двойной клик + Удержание | Активация Режима №2 «Автопоиск» |

### В Режиме №2 «Автопоиск» (управление педалью)

| Действие | Результат |
|---|---|
| Короткий клик | Установка нового центра сектора |
| Удержание | Смещение центра |
| Двойной клик | Выход из режима Автопоиска |
