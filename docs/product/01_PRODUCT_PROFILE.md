# Kona Compass — Product Profile (Draft)

## Что это
Kona Compass — умный ротатор для управления датчиком live sonar / live-эхолота.

## Для кого
Для рыболовов, которые используют:
- Garmin Panoptix LiveScope
- Lowrance ActiveTarget
- Humminbird Mega Live

## Задача продукта
Дать пользователю более точный и удобный контроль направления датчика, чем при ручных и менее продуманных решениях.

## Заявленные особенности
- точность от 0.3°
- компас
- пульт ДУ
- ножные педали
- 5 режимов работы
- 6 скоростей
- автопоиск в секторах 20°–340°
- низкое энергопотребление
- тихий мотор
- плавное вращение
- нержавеющая сталь + герметичный алюминиевый корпус
- совместимость с Garmin / Lowrance / Humminbird
