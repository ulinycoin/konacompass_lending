# Kona Compass — Technical SEO Baseline

## Обнаруженные проблемы текущего сайта

### Critical
1. Не доведена доменная канонизация (non-www / www).
2. Нет нормального robots.txt.
3. Нет стандартного sitemap.xml.
4. Нет canonical tags.
5. Нет hreflang при мультиязычности.

### High
6. Нет meta description.
7. Слабые title.
8. Нет structured data.
9. Часть контента / инструкция выглядит как embed, а не нормальный HTML.

### Medium
10. Почти нет alt-текстов у изображений.
11. Слабая контентная глубина.
12. Недостаточно trust-сигналов.

## Вывод
Новый сайт должен строиться как SEO-ready проект с нормальной HTML-структурой, а не как косметический редизайн текущей страницы.
