# Kona Compass — SEO Strategy v1

## Цель
Создать SEO-фундамент под продуктовый спрос и будущий контент-маркетинг.

## Основные кластеры спроса
1. Live sonar rotator
2. Garmin LiveScope rotator
3. Lowrance ActiveTarget rotator
4. Humminbird Mega Live rotator
5. live sonar transducer mount / aiming system
6. live sonar target lock / scanning system

## Структура SEO на старте
- Главная / продуктовый лендинг
- Compatibility
- How It Works
- Installation / Instruction
- FAQ
- Contact / Dealer inquiry

## Метаданные
Для каждой страницы нужны:
- уникальный title
- unique meta description
- canonical
- language-specific metadata
- OG / Twitter tags

## Structured Data
Минимум:
- Organization
- Product
- FAQPage (если FAQ реально видим)
- ContactPoint

## International SEO
Если сайт мультиязычный:
- отдельные URL на язык
- корректные lang
- hreflang
- консистентная внутренняя перелинковка между версиями

## Контент-рост
После запуска лендинга можно добавлять статьи:
- Garmin LiveScope setup guides
- how to aim live sonar better
- live sonar rotation benefits
- Garmin vs Lowrance vs Humminbird compatibility content
