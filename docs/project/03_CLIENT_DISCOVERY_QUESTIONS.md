# Kona Compass — Client Discovery Questions

## 1. Продукт
1. Какая точная модель / версия продукта сейчас продаётся?
2. Есть ли несколько комплектаций?
3. Какая цена?
4. Что входит в комплект поставки?
5. Какие точные технические характеристики: вес, размеры, питание, материалы?
6. Есть ли спецификация по установке?
7. Есть ли ограничения по совместимости?
8. Есть ли таблица совместимости по конкретным моделям Garmin / Lowrance / Humminbird?
9. Что в продукте самое сильное по сравнению с аналогами?
10. Есть ли патенты / собственные инженерные решения / уникальный алгоритм?

## 2. Продажа и логистика
1. Как сейчас оформляются заказы?
2. Куда вести лида: форма, WhatsApp, Telegram, email, звонок?
3. В какие страны продаёте?
4. Есть ли доставка по ЕС / США / СНГ?
5. Какие сроки изготовления / отправки?
6. Есть ли склад или всё под заказ?
7. Есть ли возврат / гарантия / сервис?
8. Есть ли дилеры или партнёры?

## 3. Бренд
1. Оставляем ли название Kona Compass без изменений?
2. Есть ли логотип в векторе?
3. Есть ли фирменные цвета / шрифты / брендбук?
4. Как бренд должен ощущаться: premium, rugged, technical, tournament-grade, etc.?
5. Кто основной рынок: Латвия, Европа, США, СНГ?
6. Какие языки обязательны на старте?

## 4. Материалы
1. Есть ли качественные фото продукта?
2. Есть ли фото продукта на лодке / в реальном использовании?
3. Есть ли видео работы устройства?
4. Есть ли видео установки?
5. Есть ли отзывы клиентов?
6. Есть ли отзывы от узнаваемых рыболовов / спортсменов?
7. Есть ли документация / инструкция / PDF?
8. Есть ли логотипы совместимых брендов, которые можно законно показывать?

## 5. Маркетинг
1. Откуда сейчас приходят клиенты?
2. Какие каналы уже пробовали?
3. Есть ли Instagram / YouTube / Facebook / TikTok?
4. Есть ли рекламный бюджет?

6. Есть ли конкуренты, которых вы считаете основными?
