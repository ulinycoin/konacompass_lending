# Kona Compass — Client Gaps Pack V1

## Purpose
Собрать только те вопросы, без которых нельзя честно и сильно добить финальную версию лендинга Kona Compass.

## Usage
Отправить клиенту как короткий structured list. Цель не устроить допрос, а быстро закрыть пробелы, которые мешают нормальной продаже.
