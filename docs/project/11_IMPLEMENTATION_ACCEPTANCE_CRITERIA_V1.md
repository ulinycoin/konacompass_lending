# Kona Compass — Landing Implementation Acceptance Criteria V1

## Product clarity
- На первом экране понятно, что это live sonar rotator.
- На первом экране видна совместимость с Garmin / Lowrance / Humminbird.
- CTA виден без скролла.

## UX
- Страница хорошо читается на мобильном.
- Секции идут в логике problem -> solution -> proof -> CTA.
- Нет ощущения сырого шаблона без структуры.

## Content coverage
- На странице отражены ключевые claims из product draft.
- Есть секции features, modes, FAQ, contacts.
- Видео / demo block присутствует хотя бы в базовом виде.

## Technical
- Проект запускается локально.
- Нет очевидных runtime errors.
- Используется нормальная структура файлов.
- Стили не разваливаются на mobile.

## SEO base
- Есть title и meta description.
- Есть Open Graph title / description.
- Есть semantic HTML base.

## Handoff readiness
- Тексты можно легко редактировать.
- Контакты и CTA можно легко менять.
- Проект можно дальше развивать без переделки с нуля.
