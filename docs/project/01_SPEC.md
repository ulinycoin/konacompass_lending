# Kona Compass — Short Spec

## Project
Разработка нового продающего лендинга и базовой digital-упаковки бренда Kona Compass.

## Primary Goal
Превратить нишевый продукт с низким уровнем упаковки в понятный, доверительный и конверсионный бренд-сайт, который помогает продавать продукт и собирать лиды.

## Business Goal
Увеличить доверие к продукту, улучшить объяснение ценности и подготовить основу для стабильного потока заявок / заказов.

## Core Jobs To Be Done
1. Объяснить, что это за продукт.
2. Быстро показать, зачем он нужен рыболову.
3. Подтвердить совместимость с ключевыми системами.
4. Показать преимущества перед альтернативами.
5. Снять страхи перед покупкой.
6. Довести пользователя до заявки, контакта или заказа.

## Deliverables
- новый sitemap / структура лендинга,
- продающий контент-каркас,
- бренд-платформа v1,
- UX/UI-концепция лендинга,
- SEO-ready структура,
- CTA и lead-capture сценарии,
- roadmap по запуску контента и продвижения.

## Non-Goals на первом этапе
- полноценный e-commerce со сложной корзиной,
- большой дилерский кабинет,
- мобильное приложение,
- глубокая CRM-интеграция,
- многостраничный каталог ассортимента.

## Primary Audience
- рыболовы, использующие live sonar,
- владельцы Garmin / Lowrance / Humminbird,
- продвинутые anglers, которым важно точное позиционирование датчика,
- потенциальные дилеры / партнёры (вторично).

## Primary Conversion
Оставить заявку / написать продавцу / запросить цену / запросить консультацию / оформить предзаказ.

## Secondary Conversion
- переход в Instagram,
- запрос инструкции,
- просмотр видео,
- сохранение контактов,
- контакт для дилерства.

## Constraints
- продукт нишевый и технический,
- бренд пока слабый,
- возможно мало контента и мало исходных фото/видео,
- текущий сайт не должен определять новую архитектуру.

## Guiding Principle
Не “обновить страницу”, а построить новый коммерческий вход в продукт.
