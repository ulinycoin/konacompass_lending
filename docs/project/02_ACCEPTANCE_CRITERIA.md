# Kona Compass — Acceptance Criteria

## Продуктовая ясность
- С первого экрана пользователь понимает, что это за устройство.
- За 10–15 секунд понятно, для кого продукт и какую проблему он решает.
- Совместимость с Garmin / Lowrance / Humminbird показана ясно.

## Доверие
- На сайте есть понятные контакты.
- Есть блок, который отвечает на вопрос: кто стоит за продуктом.
- Есть гарантия / условия / процесс покупки или заказа.
- Есть доказательства реальности продукта: фото, видео, инструкция, демонстрации, отзывы или кейсы.

## Продажи
- Есть явный CTA на каждом ключевом участке страницы.
- Пользователь понимает, какой следующий шаг делать: написать, позвонить, оставить заявку, запросить цену.
- Захват лида реализован без двусмысленности.

## UX
- Страница сильно читается с телефона.
- Блоки идут в логике: проблема -> решение -> доверие -> действие.
- Нет ощущения “самодельной витрины без структуры”.

## SEO / структура
- Есть корректные title / description / canonical / hreflang.
- Есть индексируемая HTML-структура, а не только embed-контент.
- Есть минимум базовой schema markup.
- Архитектура годится для дальнейшего SEO-расширения.

## Реализация
- Проект не зависит от Google Sites.
- Контент, дизайн и структура годятся для дальнейшего масштабирования.
- После запуска можно вести аналитику и запускать трафик.
