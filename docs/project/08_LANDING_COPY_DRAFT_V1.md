# 3. Problem

## Section title
Live sonar is powerful. Manual control is the weak point.

## Body copy
Live sonar gives anglers a huge advantage, but only when transducer control keeps up. Constant manual correction can be distracting, slow, and frustrating, especially when fish movement changes fast and every second matters.

When control is awkward, the whole system becomes harder to use. Instead of focusing on the water, the angler is forced to spend more time adjusting direction, correcting position, and reacting too late.

## Problem bullets
- Hard to keep a stable, accurate direction on target
- Too much manual correction while fishing
- Slower reaction when fish move
- More distraction, less confidence
