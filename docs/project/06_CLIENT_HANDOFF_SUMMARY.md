# Kona Compass — Client Handoff Summary

## Что мы видим на старте
У продукта есть основа, но нет сильной коммерческой упаковки.

## Главная возможность
Сделать не просто новый сайт, а полноценный брендовый вход в продажи:
- сильный лендинг,
- доверительная подача,
- понятная воронка,
- база для SEO и контента.

## Что нужно от клиента
- продуктовые данные,
- фото / видео,
- цена / заказ / гарантия,
- ожидания по рынкам и языкам,
- понимание каналов продаж.

## Что мы готовы дать
- структуру сайта,
- стратегию упаковки,
- бренд-направление,
- SEO-ready архитектуру,
- conversion-first подход.
