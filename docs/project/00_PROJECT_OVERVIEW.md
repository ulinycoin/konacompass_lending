# Kona Compass — Project Overview

## Контекст

Kona Compass — нишевый продукт для рыболовов: умный ротатор для live sonar / live-эхолотов. На текущий момент у проекта есть продукт и базовый сайт, но практически отсутствуют сильная бренд-упаковка, продающая подача, нормальная воронка лидов и масштабируемая digital-база.

## Главная задача

Создать новую основу проекта:
1. продающий лендинг,
2. внятную бренд-упаковку,
3. базу для SEO,
4. инфраструктуру для генерации и обработки лидов,
5. основу для дальнейшего контент-маркетинга и продаж.

## Почему это нужно

Текущий сайт:
- слабо объясняет ценность продукта,
- не снимает возражения,
- почти не формирует доверие,
- технически слаб для SEO,
- не выглядит как бренд, готовый к масштабированию.

## Целевой результат

После первого этапа у проекта должны появиться:
- понятное позиционирование,
- структура лендинга,
- список нужных материалов,
- согласованный scope работ,
- база для дизайна и реализации,
- готовность к запуску продаж через сайт.
