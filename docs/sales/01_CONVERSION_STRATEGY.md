# Kona Compass — Conversion Strategy

## Primary Conversion
Запрос цены / заявка / сообщение менеджеру / предзаказ.

## Recommended CTA hierarchy
1. Request Price
2. Get Consultation
3. Check Compatibility
4. Become a Dealer

## Lead Capture Options
### Best default
Простая форма + быстрый канал связи (WhatsApp / Telegram / email).

### Что важно
- не заставлять пользователя искать, куда писать,
- не прятать цену / логику заказа слишком глубоко,
- быстро отвечать после заявки,
- иметь понятную post-submit механику.

## Trust Triggers Needed
- реальные фото продукта,
- фото на лодке,
- демонстрация работы,
- гарантия,
- контакты,
- страна / производитель,
- видео установки,
- отзывы.

## Friction Points to Remove
- неясно, подходит ли продукт,
- неясно, сколько стоит,
- неясно, как заказать,
- неясно, кто продавец,
- неясно, есть ли доставка / гарантия.
